# 🧠 FridgeGPT 🍳

FridgeGPT is an AI-powered recipe generator built using LangChain, HuggingFace embeddings, and GPT via OpenRouter. Just enter what's in your fridge — and FridgeGPT will cook up creative meal ideas in real-time!

## 💡 Features

- 🔎 RAG-powered recipe lookup
- ⚡ GPT-style streaming output
- 🍽️ Cooking modes: Normal, Vegan, Student, Hangover
- 🧠 Built with LangChain + Streamlit
- 💬 Open-source & fun to use

## 🚀 Running Locally

```bash
git clone https://github.com/aniruddh1297/FridgeGPT.git
cd FridgeGPT
pip install -r requirements.txt

Create a .env file:
OPENROUTER_API_KEY=your-api-key


Then run:
streamlit run app.py
